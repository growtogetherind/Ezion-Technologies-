# Ezion-Technologies-

Premium, modern, fully responsive one-page website for **Ezion Technologies**.

## Overview
- **Brand Palette**:
  - Primary Deep Navy: `#0B2545`
  - Primary Teal: `#13A89E`
  - Light Teal: `#7DD3D0`
  - Soft Teal Background: `#E8F8F7`
  - Page Background: `#F8FAFC`
  - Text Primary: `#172033`
  - Text Secondary: `#64748B`
- **Typography**: Google Fonts [Outfit](https://fonts.google.com/specimen/Outfit) for headlines & branding + [Inter](https://fonts.google.com/specimen/Inter) for clean body & UI.
- **Theme**: Light theme corporate design with subtle overlapping circles motifs inspired by the Ezion logo.

## Structure
- **Header**: Sticky navigation with SVG logo, desktop menu, mobile drawer, and "Get a Quote" CTA.
- **Hero Section**: Eyebrow, bold headlines, supporting copy, trust statement, and interactive abstract global network visualization (connecting Canada, USA, UK, UAE, and India).
- **Trust Strip**: 4 core value pillars with line icons.
- **About Ezion**: Narrative, strategic pillars, and animated counter statistics.
- **Services**: Categorized into *Branding & Marketing* and *IT & Technology* with interactive filter tabs.
- **Offshore Outsourcing**: 7 dedicated service cards, cost advantage badge, and 3 engagement models (*Fixed Project, Monthly Retainer, Dedicated Resource*).
- **Global Reach**: Canada, USA, UAE, and UK presence with India as the primary delivery center.
- **Why Ezion**: 6 core feature blocks with numbered indicators.
- **How We Work**: 5-step structured process timeline (Discovery → Proposal → Execution → Review → Delivery & Support).
- **CTA Banner**: Deep navy accent banner with glowing teal motifs.
- **Contact & Operations**: Dual-column operations hub (India: Neeta B. Togare & Swapnil B. Togare; Canada: Vivek Jain) and enquiry form.
- **Interactive Modals**: "Get a Quote" proposal builder modal with live form feedback.
